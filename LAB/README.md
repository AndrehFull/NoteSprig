# Manual fixtures

This directory contains synthetic examples for experimenting with Markdown, YAML, links across folders, headings and blocks, tasks, search, attachments, and JSON Canvas.

- `notes/`: navigation and search examples.
- `attachments/`: example assets.
- `canvas/`: an example canvas document.
- `RUN/`: local browser profiles, traces, and experiment output; ignored by Git and Docker.

The automated suite creates its own disposable vaults from `tests/`. Do not substitute a personal vault for test data. See the [contribution guide](../CONTRIBUTING.md) for reproducible checks.
